# Gusic branding master

`gusic-icon-master.png` is the single approved master artwork for the Gusic brand:
a blue-gradient square with a translucent (glassmorphism) music note, 324x324,
8-bit RGBA PNG.

- Approved by the project owner during the 2026-10 rebrand; the design brief and
  acceptance criteria live in
  [docs/aegis/plans/2026-10-07-gusic-brand-local-library.md](../../docs/aegis/plans/2026-10-07-gusic-brand-local-library.md).
- Copied verbatim from the owner-approved candidate (SHA-256
  `20e11c06…afa14f81`). Do not edit, redraw, or overwrite this file in place.
- All branding exports — launcher adaptive/legacy/monochrome layers, the
  notification glyph, About/README and store listing icons — must be derived
  from this master, and new derivatives should be compared against it.
